Data and examples数据与示例

Read the BOP sample读取 BOP 示例数据

The small pack cache/samples/bop/lmo/ has the eight LM-O[1] meshes and two frames of scene 2, under test/000002/. Image 1 is the frame examples/05_bop_6d_detection.py reads. It is not a row of test_targets_bop19.json. Image 307 is a BOP test target, and examples/04_6d_localization.py reads it with one known count for each of the eight categories. The source snippets below read the CADs and image 307 in example 04. The reader does not look for a .pt file. It lists every models/obj_######.ply and takes the number in the file name as obj_id. The English word is the LM-O name for that id. The ply does not store it. mesh is the geometry loaded from that file.

示例包 cache/samples/bop/lmo/ 里是 LM-O[1] 的八个网格，以及场景 2 的两帧，在 test/000002/。第 1 帧是 examples/05_bop_6d_detection.py 读的那一帧，它不在 test_targets_bop19.json 里。第 307 帧是 BOP 测试目标，examples/04_6d_localization.py 读取的即是该帧，八个类别各有一个预先给定的数量。下方源码片段展示示例 04 中的 CAD 读取与第 307 帧加载。读取器不检索 .pt。它列出每一个 models/obj_######.ply，把文件名里的数字当成 obj_id。英文是 LM-O 给这个编号的名字，ply 里不存这个名字。mesh 是从该文件读入的网格。
